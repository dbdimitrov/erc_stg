# additional_info — raw source material for the Helmholtz Munich AIH PI call

All files are original page text converted to markdown (curl + pandoc, or PubMed/Semantic Scholar/GEPRIS/CORDIS API output). No summaries or commentary. Each file opens with a provenance header (`source_url`, `fetched`, `conversion`). Fetched 2026-09-21.

## The call
- `job_posting_live.md` — live posting, clean single column (role, both tracks, profile, offer, contacts, deadline). **Use this one.**
- `JobPosting.md` — same posting converted from the saved PDF; two-column layout garbled by OCR. Kept as the archival copy.
